# Plan: 功能名稱

## Goal

誰會使用、要解決什麼問題，以及完成後應該看到的結果。

## Current behavior

目前的操作方式與限制。

## Architecture / flow

必要時使用 Mermaid 表示頁面、API、資料庫與外部服務的關係。

## Scope

### May modify

- 可修改的頁面、元件、API 或設定。

### Must not modify

- 不可改變的內容、資料、品牌或安全邊界。

## Existing patterns to follow

- 應沿用的元件、命名、驗證與發布方式。

## Constraints

- 相容性、效能、隱私、裝置與託管限制。

## Verification

1. 正常使用情境。
2. 錯誤或未授權情境。
3. 手機版或其他容易退步的情境。

## Done definition

- [ ] 功能符合需求。
- [ ] 型別、建置與測試通過。
- [ ] 安全與秘密掃描通過。
- [ ] 差異已由人確認。
- [ ] 取得正式發布授權。

## Risks and rollback

可能造成的影響，以及出現問題時如何回到上一個正常版本。

## Open questions

- 實作前仍需要決定的事項。
